## 实习表头与编号条目

### 单项目

```markdown
**{公司}**  {岗位名称}  {2025.06-2025.12}

1. **需求调研与方案设计**：针对{场景}{痛点}，通过竞品调研与用户访谈梳理需求，输出方案文档并推动评审落地，核心转化率提升 **12%**。
2. **数据驱动迭代**：结合行为数据优化运营策略，对照实验验证后点击率上升、无效曝光下降，支撑上线复盘。
```

### 多项目并列（推荐格式）

```markdown
**示例科技有限公司**  示例岗位实习生  2025.12-至今

**项目一：核心业务流程优化**
面向业务增长场景，参与流程梳理、方案评审与阶段性交付落地。

1）**规划与跨团队交付：**协助拆解评审、联调、灰度里程碑，协调业务、研发与测试对齐需求文档与验收口径，覆盖关键行动项闭环。
2）**质量验收与变更管理：**建立问题样本归因机制；核心指标 **提升 12%**，支撑变更评审。

**项目二：内部协作工具建设**
参与内部工具从 0 到 1，覆盖需求收集、查数、答疑与巡检的立项到双渠道上线。

1）**立项与进度管理：**梳理工单与多渠道入口，输出最小可行版本与 **三阶段路线图**。
2）**交付协同与节点验收：**推动双渠道上线，结项交付 **13+ 功能模块、40+ 配置项**。
3）**风控治理与持续迭代：**搭建 **6 项评估指标**及权限分级、数据脱敏规范。

**示例制造集团**  示例岗位实习生  2025.06-2025.12

**项目：流程数字化改造**
参与企业内部系统规划与落地，覆盖需求调研、流程优化与上线推广。

1）**项目立项与范围规划：**……
2）**项目推进与阶段验收：**关键流程效率提升 **20%**，任务准确率提升 **13%**。
3）**流程管控与推广复盘：**累计沉淀 **5800 条**标准条目；培训评分 **4.5/5**。
```

格式要点：

- `**项目一：…**` 单独一行；简介下一行、**Markdown 不加粗**，导出为**灰色斜体**；简介 **仅 1 行 / 1 句**（约 25–45 字）点明场景与边界，不与条目重复；禁止写成多句长段。
- 章节标题导出为**浅灰底栏 + 左侧竖条**。
- `1）` 从行首顶格写，行前无空格；任务名 `**加粗：**`，量化结果 `**加粗**`。
- **行宽写满**：每条经历写满 2–4 个分句（约 80–140 字），技能四行写到接近行末；禁止正文半句结束导致 PDF 每行只占半截。
- 经历正文用通顺中文；`query/PRD/badcase/pp` 等见 [reference.md](reference.md) 替换表。
- 编号条目数量不设硬上限；不要用 `-` 无序列表。一页紧张时用 `tight`/`compact` 或压缩措辞。

## 相关技能（固定 4 行）

```markdown
---
## 相关技能

1. **工作技能**：具备需求调研、跨部门协同、里程碑跟进与验收复盘能力，可支撑{目标岗位}核心场景。
2. **数据技能**：掌握 Python、SQL、Excel（数据透视表 / VLOOKUP），能够完成数据提取、指标复盘、对比分析与项目材料沉淀。
3. **AI技能**：熟悉常用办公与协作工具的使用方法，能够在需求调研、方案验证、交付验收与风险治理等环节完成协作支持；目标岗位涉及专业工具栈时可在此定向补充。
4. **语言能力**：雅思 **7 分**，可支持英文资料阅读、邮件与会议沟通。
```

## PDF 文件名

```text
{公司}+{姓名}+{岗位}.pdf
```

示例：`示例公司+张三+示例岗位.pdf`

终稿勿用：`示例公司+张三+示例岗位_填充版.pdf`

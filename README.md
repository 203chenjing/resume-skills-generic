# resume-skills-generic

Two Cursor Agent Skills for Chinese resume workflows — archive your experience, then tailor to each JD.  
两个 Cursor Agent 技能：简历素材库归档 + 定向改写投递。

## Install / 安装

Copy both folders into `.cursor/skills/` (project) or `~/.cursor/skills/` (global):

| Folder | Purpose |
|--------|---------|
| [`resume-database-generic/`](resume-database-generic/) | Build & maintain `简历数据库.md` — STAR, metrics, open items (archive only) |
| [`resume-tailor-generic/`](resume-tailor-generic/) | Tailor resume to a JD, STAR rewrite, one-page PDF export |

See each skill's `README.md` and `SKILL.md` for details.
